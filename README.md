# JsKids Browser

Um navegador próprio desenvolvido com Electron, focado em controle e estudo.

## 🎯 Features

- ✅ Abas personalizadas
- ✅ Navegação (voltar, avançar, recarregar)
- ✅ Barra de endereços inteligente
- ✅ Busca integrada no Google
- ✅ Suporte a múltiplas abas

## 🚀 Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/JsKids-Browser.git
cd JsKids-Browser

# Instale as dependências
npm install

# Execute em modo desenvolvimento
npm start
```

## 🔨 Build

```bash
# Build para Linux (AppImage)
npm run dist

# Build rápido (sem empacotar)
npm run fast
```

## 📁 Estrutura do Projeto

```
JsKids-Browser/
├── main.js           # Processo principal do Electron
├── renderer.js       # Lógica da interface
├── preload.js        # Bridge de segurança
├── index.html        # Estrutura HTML
├── styles.css        # Estilos
├── package.json      # Dependências e scripts
└── assets/           # Ícones e recursos
```
